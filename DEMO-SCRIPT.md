# Demo video outline (about 4 minutes)
Use two browser windows (one normal, one private) so you can be seller and buyer at once. Run `npm run seed` first.

1. **0:00 Problem (20s):** "Campus buying and selling happens in chat groups: no search, lost haggling, double-selling."
2. **0:20 Seller lists (30s):** log in as Ravi, Sell page, list an item.
3. **0:50 Browse and save (30s):** as Asha, search and filter, save the item to the wishlist.
4. **1:20 Price-drop alert (30s):** as Ravi, change the price lower; as Asha, show the alert badge and the wishlist highlight.
5. **1:50 Negotiation (60s):** Asha offers; Ravi counters; Asha accepts. Show that the wrong side cannot act out of turn.
6. **2:50 Pay (45s):** Asha reserves (show the countdown), pays with Razorpay test card. Mention a second buyer would be blocked during the hold.
7. **3:35 Handover (25s):** both confirm on the Orders page; status becomes Completed.
8. **4:00 Close (10s):** one line on the stack and tests.
